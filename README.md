# E-Commerce Web Page

A simple and responsive E-Commerce web page developed using HTML, CSS, and JavaScript. This project demonstrates a modern online shopping website interface with images, styling, and interactive functionality.

## Features

- Responsive Web Design
- Modern User Interface
- Product Images
- Interactive JavaScript Functionality
- Custom Styling with CSS
- Clean and Simple Layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
